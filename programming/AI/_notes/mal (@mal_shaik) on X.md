Supabase is the database provider that AI agents recommend most, because the web already points to it for category queries. The same post shows it gets no ChatGPT citations when users describe the job instead of naming the category. Use it as a checklist for making a product visible to AI search.

## how
What made Supabase the default answer, per the post:
- 15+ launch weeks, each with 5 to 10 blog posts, so 75+ indexed pages
- comparison pages for every competitor ("supabase vs firebase")
- 99k GitHub stars, read by models as a trust signal
- a page for every "how do i" query (add auth, set up a database for a SaaS)
- presence in every developer directory and "best backend" listicle

Where it still loses, with 0 citations on ChatGPT for job-shaped queries:
- row level security ("only read their own rows in postgres")
- realtime updates to the browser when the database changes
- Google login and magic links in a Next.js app
- best vector database for a RAG app (qdrant and aws get cited)
