## data & platforms
[platform for building dev portals](https://backstage.io/) — built by spotify, extended through a growing plugin ecosystem beyond the core catalog
[edge database](https://www.geldata.com/) — the renamed edgedb, now built on postgres with its own edgeql query language
[MySQL platform](https://planetscale.com/) — originally youtube's vitess sharding tech, now also offers postgres via new neki product
[neon: postgres database](https://neon.com/) — acquired by databricks, now positioned as lakebase postgres with instant db branching
[RxDB local database for Js applications](https://rxdb.info/) — offline-first nosql store with live reactive queries and plug-in sync for graphql, couchdb, webrtc
[tinybase: local-first reactive data store & sync engine](https://tinybase.org/) — adds a sql-like query language and crdt-based sync in under 17kb

## build
[Rspack bundler](https://www.rspack.dev/) — rust-based webpack replacement claiming faster builds, part of the wider rstack tool ecosystem
[farm fe - extremely fast web build tool written in rust](https://www.farmfe.org/) — uses persistent incremental caching and partial bundling, plus compatibility with vite plugins

## utilities
[tunelling](https://github.com/unjs/untun) — wraps cloudflared to expose a local server through quick tunnels via cli
[json visualization](https://jsoncrack.com/) — also converts yaml, csv, xml into interactive tree graphs and generates typescript or go code
[penpot - figma alternative](https://penpot.app/) — open source, self-hostable, with built-in ai agents for code-to-design workflows
