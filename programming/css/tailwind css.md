## tools
[tailwind palette](https://www.tints.dev) — tunes hue, saturation and lightness by stop, outputs a v4 @theme block or v3 config
[color generator](https://uicolors.app/generate) — builds a full brand, neutral and status color system with live component previews
[box shadows in tailwind](https://ui.aceternity.com/tools/box-shadows) — curates 24 named presets, layers multiple shadows, toggles tailwind or plain css output
[tailwind merge](https://github.com/dcastil/tailwind-merge) — js function resolves conflicting classes instead of concatenating them, now supports tailwind v4.3
[tailwind to inline](https://github.com/vardan-arm/tailwind-to-inline) — converts classes to inline styles for email clients, with template variable substitution
