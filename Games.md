## procedural generation
[wave function collapse](https://github.com/mxgmn/WaveFunctionCollapse) — original c# implementation behind dozens of ports, used to generate levels in townscaper
[generating worlds with wave function collapse](https://www.procjam.sekritforum.com/tutorials/wfc/) — hands-on walkthrough sets up the overlap model in both javascript canvas code and unity prefabs
[model synthesis](https://paulmerrell.org/model-synthesis/) — paul merrell's 2007 origin algorithm that wfc reimplements, focused on 3d instead of 2d
[hexagonal grids](https://www.redblobgames.com/grids/hexagons/) — interactive guide revised through 2026 recommends axial or cube coordinates over offset systems

## shipping
[Godot game engine](https://godotengine.org/) — browser-based editor needs no installation, currently at version 4.7.2 with 4.8 in development
[How To Build A Real-Time Multi-User Game From Scratch](https://www.smashingmagazine.com/2021/10/real-time-multi-user-game/) — case study still holds but the free heroku hosting it used shut down in 2022
[html5 deck of cards](https://github.com/deck-of-cards/standard-deck) — the svg card graphics behind the deck.of.cards multiplayer site
[JavaScript procedural generator for Mazes, Terrains, and Biomes](https://github.com/yantra-core/Labyrinthos.js) — unmaintained since early 2024, last npm release 1.1.2 that same year
