## syntax highlighting
[shiki](https://shiki.matsu.io/) — compiles vs code's textmate grammars into zero-runtime highlighting, code at github.com/shikijs/shiki
[jsdiff: a javascript text differencing implementation](https://github.com/kpdecker/jsdiff) — compares strings at any granularity from characters to json, then builds reversible patches

## code playground
[stackblitz](https://stackblitz.com/) — runs a full node environment client-side in the browser via webassembly webcontainers

## image
[canvas for Node.js](https://skia-canvas.org/) — matches chrome's rendering via google's skia engine and renders asynchronously across multiple threads

## auth
[better auth](https://www.better-auth.com/) — config-as-code auth framework with plugins covering sso, saml, and scim, now joining vercel
[clerk](https://clerk.com/) — ships prebuilt auth ui plus billing and b2b multi-tenancy, free under 50k monthly users

## content extraction
[defuddle: extracts the main content from web pages](https://github.com/kepano/defuddle) — debug mode shows exactly why each element got removed or kept
